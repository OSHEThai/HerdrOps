# v0.3 Issue #15 — File Activity implementation checklist

Reference: `docs/design/reference/07-file-activity.png`

## Implemented visual hierarchy

- Five summary cards: read, modified, created, deleted, and suspicious actions.
- Search plus action, task, source, date, and filter controls.
- Selectable activity table with time, Agent, action, path, task, confidence, and source.
- Synchronized file detail panel with bounded, secret-redacted diff preview.
- Activity-over-time, file-type, and high-risk/out-of-scope panels.
- Responsive density at 1,672 × 941 and 1,366 × 768.

## Language and accessibility

- Thai mode uses Thai interface copy; English mode uses English interface copy.
- Brand names, task IDs, file paths, extensions, and code remain technical data.
- Rejected paths and explanatory diff messages are localized rather than leaking English copy into Thai mode.
- Keyboard focus is visible on filters and selected rows.
- Search, filters, table, and chrome controls expose localized automation names.

## Evidence classes

- WPF screenshots use deterministic synthetic data and are labelled as UI preview evidence.
- Collector tests include real local FileSystemWatcher and Git execution in temporary authorized repositories.
- `actual-file-git-trace-release.json` is actual local runtime evidence for the committed Release binary and this repository.
- No screenshot or local trace is represented as actual Herdr Agent/Task correlation.
