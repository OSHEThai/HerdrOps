# v0.1 Issue #4 Widget and Quality Checklist

Status: Implementation evidence complete; user visual approval remains open

Authority: `docs/design/reference/11-widget-concepts.png` and `Plan/DESIGN-CONTRACT.md`

## Canonical variants

- [x] Compact Widget
- [x] Normal Widget
- [x] Expanded Widget
- [x] Floating Mini Widget
- [x] Floating Vertical Widget
- [x] Notification Widget
- [x] Agent Detail Popup
- [x] Dashboard launch/preview companion state

Every variant consumes the same deterministic `SyntheticWidgetState`. The UI displays
`SYNTHETIC DATA` or `SYN` and `Herdr not connected`; no value is represented as live Herdr data.

## Interaction and accessibility

- [x] All seven widget windows can be opened from keyboard-focusable Gallery actions.
- [x] Every open/close/pin/reset action has a UI Automation name and visible focus treatment.
- [x] Topmost can be toggled on and off without changing the underlying state.
- [x] Dragged positions are clamped to the Windows work area and can be reset with `Ctrl+0`.
- [x] `Esc` closes a widget and `Ctrl+T` reversibly toggles Always-on-top.
- [x] Primary, secondary, and accent text pairs meet WCAG AA 4.5:1 contrast in automated checks.
- [x] Explicit or system reduced-motion preference resolves transitions to zero duration.
- [x] Thai clipping checkpoints pass at the required Gallery dimensions and scale factors.
