# v0.4 Issue #19 — Assignment lifecycle implementation record

## Outcome

HerdrOps now has a versioned deterministic assignment lifecycle, append-only audit and
relationship history, current task and role projections, SQLite schema migration 2, and
a strict synthetic replay command.

## Implemented boundaries

```text
Core-accepted self-report
        |
        v
HerdrOpsAssignmentLifecycleMapper
        |
        v
AssignmentLifecycleReducer ----> deterministic audit and projections
        |
        v
SqliteHerdrStateStore ----------> append-only history plus current state
```

- Contracts own the agent-facing self-report shape.
- Core owns acceptance identity and the single mapping into the domain model.
- Domain owns lifecycle validation, transition rules, canonical hashes, and replay.
- Infrastructure owns migration, transactions, append-only SQLite ledgers, and queries.
- CLI still references only Contracts and has no SQLite access.

## Implemented controls

- Seven versioned lifecycle event kinds and seven task statuses.
- Immutable Assignment Contract provenance inside every task snapshot.
- Strict current-assignee, acknowledgement, parent-tip, monotonic-progress, evidence,
  and duplicate-handoff rules.
- Explicit consumed audit records for gaps, orphans, invalid transitions, and duplicate
  handoffs.
- Non-consuming exact duplicate and conflict handling in the reducer.
- Canonical hashes for every event, audit, state, relationship, role observation, and
  replay result.
- SQLite schema version 2 with transactional forward migration and pre-migration backup.
- Exact migration history validation before and after migration.
- Append-only event, relationship, and role-history triggers.
- Transactional prior-state hash binding that rejects disconnected histories.
- Startup replay plus exact per-step reducer matching that rejects forged dispositions
  and hidden global sequence gaps without replaying the full ledger on every commit.
- Reducer restoration after failed persistence and resynchronization after sequence drift.
- Strict persisted JSON and provenance validation on reads.
- Restart replay that reproduces the exact deterministic result hash.
- Bounded Core command `assignment-lifecycle-replay` with atomic report output.
