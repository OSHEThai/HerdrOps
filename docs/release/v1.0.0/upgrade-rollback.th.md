# การปรับรุ่นและย้อนกลับ HerdrOps v1.0.0

## กฎความปลอดภัย

- ใช้เฉพาะไฟล์บีบอัดที่ผ่านการยอมรับและบันทึกความถูกต้องที่ตรงกัน
- ปิด `HerdrOps.App`, `HerdrOps.Core` และ `HerdrOps.Cli` ก่อนเปลี่ยนไฟล์โปรแกรม
- สำรอง `%LOCALAPPDATA%\HerdrOps` ก่อนปรับรุ่น
- ห้ามผสมไฟล์จากชุดไฟล์คนละรุ่น
- ชุดไฟล์สำหรับย้อนกลับต้องเป็นชุดเดิมที่ผ่านการยอมรับจริง ไม่ใช่ไฟล์ที่สร้างใหม่จาก commit เดิม

## ปรับรุ่นจากรุ่นทดสอบที่ผ่านการยอมรับ

1. ตรวจ SHA-256 ของไฟล์บีบอัด v1.0.0
2. หยุดกระบวนการของ HerdrOps ทั้งหมด
3. คัดลอก `%LOCALAPPDATA%\Programs\HerdrOps` ปัจจุบันเป็นโฟลเดอร์สำรองชื่อไม่ซ้ำที่อยู่ข้างกัน
4. แตก v1.0.0 ลงในโฟลเดอร์พักใหม่ที่อยู่ข้างโฟลเดอร์ติดตั้ง
5. ตรวจทุกไฟล์ในโฟลเดอร์พักกับ `package-manifest.json`
6. เปลี่ยนชื่อโฟลเดอร์ติดตั้งปัจจุบันเป็นชื่อสำรอง แล้วเปลี่ยนชื่อโฟลเดอร์พักเป็น `HerdrOps`
7. เปิด `Core` และ `App` แล้วตรวจรุ่น สถานะการเชื่อมต่อ ภาษา การตั้งค่า และข้อมูลที่ต้องเก็บไว้
8. เก็บชุดไฟล์รุ่นก่อนหน้าไว้จนกว่าการยอมรับจะเสร็จสมบูรณ์

ห้ามซ่อมการปรับรุ่นที่ล้มเหลวด้วยการคัดลอก DLL ทีละไฟล์ ให้คืนโฟลเดอร์รุ่นก่อนหน้าทั้งชุด

## ย้อนกลับ

1. หยุดกระบวนการของ HerdrOps ทั้งหมด
2. เก็บสำเนาโฟลเดอร์ข้อมูลผู้ใช้ปัจจุบันไว้เพื่อวินิจฉัย
3. ตรวจชุดไฟล์รุ่นก่อนหน้ากับบันทึกความถูกต้องของชุดนั้น
4. ย้ายโฟลเดอร์โปรแกรมปัจจุบันออกไป โดยห้ามรวมไฟล์กับโฟลเดอร์สำรอง
5. คืนโฟลเดอร์โปรแกรมรุ่นก่อนหน้าทั้งชุดด้วยการสับเปลี่ยนครั้งเดียวเมื่อทำได้
6. เปิด `Core` และ `App` แล้วตรวจรุ่นเดิมและพฤติกรรมของข้อมูล

การย้ายฐานข้อมูลเป็นแบบเดินหน้าเท่านั้น การคืนข้อมูลต้องใช้คำสั่งกู้คืนตามรุ่นกับไฟล์สำรองก่อนปรับรุ่นที่ตรงกัน ห้ามแทนที่ฐานข้อมูลที่กำลังใช้งานด้วยตนเอง

## การเก็บข้อมูลเมื่อลบโปรแกรม

การลบ `%LOCALAPPDATA%\Programs\HerdrOps` จะลบไฟล์โปรแกรม ส่วน `%LOCALAPPDATA%\HerdrOps` จะยังคงอยู่ การลบข้อมูลที่เก็บไว้เป็นการกระทำแยกต่างหากของผู้ใช้ และไม่สามารถย้อนกลับได้หากไม่มีไฟล์สำรอง
