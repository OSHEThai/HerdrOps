# คู่มือผู้ใช้ HerdrOps v1.0.0

## สิ่งที่ต้องมี

- Windows 11 x64
- บัญชี Windows แบบมาตรฐานที่ไม่ได้เปิดสิทธิ์ผู้ดูแลระบบ
- ติดตั้ง Herdr แล้ว และมีช่วงการทำงานภายในเครื่องที่พร้อมใช้งาน
- ไฟล์ `HerdrOps-1.0.0-win-x64.zip` ที่ผ่านการยอมรับ และ `package-hashes.txt` ที่มาจากรุ่นเผยแพร่บน GitHub เดียวกัน

## ตรวจไฟล์ที่ดาวน์โหลด

เก็บไฟล์บีบอัดและบันทึกความถูกต้องไว้ด้วยกัน แล้วเปรียบเทียบ SHA-256 ของไฟล์บีบอัดกับค่า `ArchiveSha256` ใน `package-hashes.txt` ก่อนแตกไฟล์

```powershell
Get-FileHash .\HerdrOps-1.0.0-win-x64.zip -Algorithm SHA256
Get-Content .\package-hashes.txt
```

ห้ามดำเนินการต่อเมื่อชื่อไฟล์ จำนวนไบต์ หรือ SHA-256 ไม่ตรงกัน

## ติดตั้ง

1. ปิดกระบวนการของ HerdrOps ที่กำลังทำงานทั้งหมด
2. สร้าง `%LOCALAPPDATA%\Programs\HerdrOps` สำหรับผู้ใช้ปัจจุบัน
3. แตกไฟล์บีบอัดที่ตรวจแล้วลงในโฟลเดอร์ดังกล่าว โดยไม่รวมชั้นโฟลเดอร์และไม่เปลี่ยนชื่อไฟล์
4. ตรวจว่ามี `HerdrOps.App.exe`, `HerdrOps.Core.exe` และ `HerdrOps.Cli.exe` ครบ

ชุดไฟล์นี้ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบและไม่ติดตั้งบริการของ Windows

## เริ่มใช้งาน

1. เปิด Herdr และพื้นที่ทำงานภายในเครื่องที่ต้องการให้ HerdrOps ติดตาม
2. เปิดบริการสถานะภายในเครื่องจากโฟลเดอร์ติดตั้ง

   ```powershell
   .\HerdrOps.Core.exe serve-herdr-state
   ```

3. เปิดหน้าต่างโปรแกรม

   ```powershell
   .\HerdrOps.App.exe
   ```

4. รอให้แถบสถานะด้านล่างแยกสถานะการเชื่อมต่อ Core ออกจากสถานะการเชื่อมต่อ Herdr แบบสด หากหน้าจอระบุว่ากำลังเชื่อมต่อใหม่หรือออฟไลน์ ห้ามถือว่าสถานะ Agent ล่าสุดที่จำไว้เป็นสถานะปัจจุบัน

## ภาษาและวิดเจ็ต

ใช้ตัวเลือกภาษาบนแถบด้านบนเพื่อเลือกภาษาไทยหรืออังกฤษ หน้าจอที่มองเห็นทั้งหมดจะเปลี่ยนเป็นภาษาที่เลือก ส่วนชื่อผลิตภัณฑ์ ชื่อ Agent รหัส พาธ และค่าของโพรโทคอลจะคงรูปแบบเดิม ใช้เมนูถาดระบบหรือหน้าการตั้งค่าเพื่อเลือกและแสดงวิดเจ็ต

## หยุดใช้งานและลบโปรแกรม

ออกจากหน้าต่างโปรแกรมผ่านเมนูถาดระบบ แล้วหยุดหน้าต่าง `Core` ด้วย `Ctrl+C` เมื่อต้องการลบโปรแกรม ให้ลบ `%LOCALAPPDATA%\Programs\HerdrOps` ตามนโยบาย ข้อมูลผู้ใช้จะยังอยู่ที่ `%LOCALAPPDATA%\HerdrOps` ควรสำรองข้อมูลก่อนตั้งใจลบโฟลเดอร์ดังกล่าว

## การตีความหลักฐาน

สถานะจาก Herdr กิจกรรมที่สังเกตภายในเครื่อง ความสัมพันธ์ที่อนุมาน และการรายงานตนเองจาก Agent เป็นข้อมูลคนละแหล่ง ก่อนดำเนินการตามคำเตือนหรือคะแนน ให้ตรวจแหล่งที่มา ความเชื่อมั่น ความสด และสถานะการตรวจสอบที่แสดงอยู่ในหน้าจอ
