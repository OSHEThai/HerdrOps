# การแก้ปัญหา HerdrOps v1.0.0

## เปิดหน้าต่างได้แต่ข้อมูลไม่เป็นแบบสด

ตรวจแถบสถานะด้านล่าง การเชื่อมต่อ `Core` และการเชื่อมต่อ Herdr เป็นคนละสถานะ ตรวจว่า `HerdrOps.Core.exe serve-herdr-state` ทำงานอยู่ภายใต้ผู้ใช้ Windows คนเดียวกัน และเปิดช่วงการทำงานของ Herdr ที่ต้องการแล้ว ห้ามตีความสถานะกำลังเชื่อมต่อใหม่หรือออฟไลน์ว่าเป็นสถานะ Agent ปัจจุบัน

## `Core` เริ่มทำงานไม่ได้

เปิด `Core` จากหน้าต่าง PowerShell แบบมาตรฐานในโฟลเดอร์ติดตั้ง แล้วอ่านข้อผิดพลาดแรกที่แสดง ตรวจว่าทุกไฟล์มาจากไฟล์บีบอัดเดียวกัน และ SHA-256 ของไฟล์บีบอัดตรงกับ `package-hashes.txt` ห้ามเปิดสิทธิ์ผู้ดูแลระบบเพื่อข้ามปัญหาพาธหรือช่องสื่อสารของผู้ใช้ปัจจุบัน

## เปิดหน้าต่าง `App` ชุดที่สองไม่ได้

HerdrOps อนุญาตให้ผู้ใช้หนึ่งคนเปิดโปรแกรมได้ครั้งเดียว ให้เรียกหน้าต่างเดิมจากถาดระบบ หากไม่มีไอคอนในถาดระบบ ให้ตรวจว่ากระบวนการเดิมปิดแล้วก่อนเปิดใหม่

## หน้าจอแสดงภาษาผิด

เลือกภาษาไทยหรืออังกฤษจากแถบด้านบน หน้าจอต้องแสดงภาษาที่เลือกเพียงภาษาเดียว หากพบข้อความสองภาษาซ้อนกันในหน้าเดียว ให้บันทึกภาพหน้านั้นและรายงานเป็นข้อบกพร่อง

## ไม่พบวิดเจ็ต

เปิดเมนูถาดระบบ ตรวจชนิดวิดเจ็ตและสถานะเปิดใช้งาน แล้วสั่งแสดงอีกครั้ง หากใช้หลายจอ ให้ตรวจขอบจออื่นเมื่อจุดที่บันทึกไว้เดิมอยู่นอกพื้นที่มองเห็น

## การตั้งค่าหรือข้อมูลมีอาการเสียหาย

หยุด `App` และ `Core` แล้วเก็บสำเนา `%LOCALAPPDATA%\HerdrOps` ก่อนกู้คืน ใช้คำสั่งวินิจฉัยและกู้คืนของรุ่นที่ติดตั้ง ห้ามลบหรือแทนที่ไฟล์ SQLite ที่กำลังถูกใช้งานโดยกระบวนการของ HerdrOps

## การปรับรุ่นล้มเหลว

ห้ามคัดลอกไฟล์โปรแกรมบางไฟล์ทับการติดตั้งที่ล้มเหลว ให้หยุดกระบวนการทั้งหมดและทำตามขั้นตอนคืนโฟลเดอร์ทั้งชุดใน `upgrade-rollback.th.md` เก็บชุดไฟล์ที่ล้มเหลวและสำเนาข้อมูลไว้เพื่อวินิจฉัย

## รายงานปัญหา

ระบุรุ่น HerdrOps รุ่น Windows สถานะการเปิดสิทธิ์ผู้ดูแลระบบ สถานะการเชื่อมต่อ `Core` และ Herdr เวลาที่เกิดเหตุ หน้าแดชบอร์ดหรือวิดเจ็ตที่เกี่ยวข้อง และชุดข้อมูลวินิจฉัยที่ลบข้อมูลอ่อนไหวแล้ว ห้ามแนบกุญแจบริการ โทเคน ข้อมูลลับ ข้อความจากหน้าต่างคำสั่งที่ไม่เกี่ยวข้อง หรือเนื้อหาไฟล์ส่วนตัว
