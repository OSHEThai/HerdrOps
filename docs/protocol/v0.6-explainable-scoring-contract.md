# v0.6 Explainable Scoring Contract

Issue: [#30](https://github.com/OSHEThai/HerdrOps/issues/30)

## Formula v1

`HERDROPS-EVALUATION-V1` uses six dimension weights:

| Dimension | Weight |
| --- | ---: |
| Goal Alignment | 20% |
| Acceptance Criteria | 20% |
| Technical Quality | 20% |
| Scope Compliance | 15% |
| Evidence | 15% |
| Communication | 10% |

Each dimension keeps the three source values separate. Leader and Project Manager values contribute
30% each and objective evidence contributes 40%. The engine never replaces one source with another.

## Missing and invalid data

A score is valid only when it is an integer from 0 through 100 and carries a non-empty provenance
identity plus a 64-character SHA-256. A complete total requires all 18 source values. Missing input
produces `Incomplete`; an invalid score, invalid provenance, or duplicate dimension produces
`Invalid`. In both cases the total remains null. `AvailableWeightBasisPoints` shows only dimensions
that were complete without presenting the partial value as a passing total.

## Determinism and history

Formula weights use integer basis points. Dimension values and weighted contributions round to four
decimal places away from zero; a complete total rounds to two places away from zero. Dimension order
is normalized before hashing.

Every result retains the complete normalized formula and input snapshot. Separate SHA-256 values bind
the formula, input snapshot, and result. Recalculation uses the retained formula, so adding a later
formula version does not change historical results. Before returning a recalculation, the engine
verifies the recorded result hash, retained formula hash, retained input hash, and reproduced result
hash; altered history fails closed.

## Evidence boundary

The golden JSON fixture and Unit tests provide Static and Unit evidence for deterministic arithmetic,
source separation, fail-closed missing/invalid behavior, and historical recalculation. They do not
prove production score ingestion, role authority, Evaluation page rendering, actual Herdr Runtime,
or v0.6 Release readiness.
