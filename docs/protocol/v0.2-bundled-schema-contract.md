The request union must contain `session.snapshot` and `events.subscribe`. The success-response

`pane.agent_status_changed`.

## Fail-closed behavior

The extractor first runs the Issue #6 exact-binary admission. It then requires one unique schema
start, a balanced object within 4 MiB, strict UTF-8, valid JSON, the admitted draft/protocol/schema
version, all groups and definitions above, exact definition counts, required variants, exact raw
length, and exact raw SHA-256.

Missing, duplicate, truncated, oversized, malformed, unsupported, incomplete, changed-length, or
changed-hash documents return a non-compatible status. A rejected result never exports schema
bytes.

## Evidence boundary

This is `Contract` evidence from static executable bytes. The extractor does not invoke the Herdr
CLI, connect to a Named Pipe, inspect or control a session, or prove snapshot/event/reconnect
behavior. Those runtime claims remain Issue #7 gates.
