# v0.2 role-distinct runtime-review receipt contract

This contract is a bounded verifier for Issues #7, #9, #10, #11, and #149. It
consumes two already-held, actual-Herdr `Runtime/PASS` evidence directories
(one `Thai`, one `English`) plus the atomic language-matrix candidate and the
accepted package identity inputs. It does not launch Herdr, open a session,
capture UI, or grant release authority.

## Inputs and bindings

`tools/v0.2-runtime-review/Test-V02RuntimeReviewReceipt.ps1` requires:

- exact lowercase `ExpectedSourceCommit` and `ExpectedSourceTree` and a clean
  checkout at those identities;
- the package identity receipt, archive, and extracted package root. The
  committed package verifier runs first, then this verifier re-reads the
  receipt, archive, real `package-manifest.json`, `HerdrOps.App.exe`, and
  `HerdrOps.Core.exe` from bounded held file handles and cross-checks bytes and
  SHA-256 values;
- distinct Thai and English evidence trees. Each tree must contain the gate,
  App/Core reports, progress report/history, capture files, and TRX selection
  receipt. Every accepted file is inventoried, bounded, non-reparse, and
  hashed. Gate paths must resolve to the real files inside that evidence tree;
- the atomic `RuntimeMatrixCandidate` file. Its canonical payload hash, two
  unique language legs, source/package/App/Core bindings, and file hash are
  independently checked;
- `BuilderIdentity`, `RuntimeOperatorIdentity`, `MatrixProducerIdentity`, and
  `RuntimeReviewerIdentity`. The reviewer is rejected when equal to any of the
  other three after trimming, case-insensitively. Aliases are not distinct
  authority;
- a new output path below the common evidence parent. Publication uses a
  unique temporary file, flush, final reparse check, and no-clobber atomic move.

The source, package, gate, report, session, Herdr executable/schema/protocol,
semantic event, capture, progress, and matrix hashes are carried into the
receipt. Control and target session names/sockets must be distinct. Required
semantic evidence includes actual Core runtime/snapshot/event/reconnect
observations, App Event A and Event B transitions, and eight language-matched
captures.

## Invocation shape

Run from a clean, exact source checkout after the two actual runtime runs and
matrix publisher have finished:

```powershell
pwsh -NoProfile -File .\tools\v0.2-runtime-review\Test-V02RuntimeReviewReceipt.ps1 `
  -ThaiEvidenceDirectory <absolute-held-thai-pass-directory> `
  -EnglishEvidenceDirectory <absolute-held-english-pass-directory> `
  -MatrixCandidatePath <absolute-atomic-language-matrix-candidate.json> `
  -PackageIdentityPath <absolute-package-identity-receipt.json> `
  -PackageArchivePath <absolute-package.zip> `
  -ExtractedPackageRoot <absolute-extracted-package-root> `
  -RepositoryRoot <absolute-clean-worktree> `
  -ExpectedSourceCommit <40-lowercase-hex> `
  -ExpectedSourceTree <40-lowercase-hex> `
  -OutputPath <new-absolute-candidate-path> `
  -BuilderIdentity <identity> `
  -RuntimeOperatorIdentity <identity> `
  -MatrixProducerIdentity <identity> `
  -RuntimeReviewerIdentity <independent-identity>
```

The output must validate against
`tools/v0.2-runtime-review/runtime-review-receipt.schema.json` and has
`EvidenceClassification=IndependentReviewCandidate`.

## Authority boundary

The output is a candidate, even when all supplied inputs validate. It always
contains `IndependentReview=NOT_OBSERVED`,
`ExternalReviewerAttestation=NOT_PROVIDED`, `HumanVisualGo=NOT_OBSERVED`,
`RuntimeCredit=false`, and `ReleaseCredit=false`. Caller-authored role or
status fields cannot promote it. A separately authenticated independent
reviewer must attest to the complete candidate and every carried hash through
the release authority process; that attestation is not synthesized by this
tool. A future verifier must reject an attestation that is copied, stale,
forged, mixed-language, partial-leg, or not bound to the exact candidate
bytes.

The selftests use only temporary mock files and do not install, start, or
observe the product. They are Static/Contract/Synthetic evidence, not Runtime,
Human visual, or Release evidence.
