# HerdrOps v0.7 Live Performance Measurement Producer Contract

## Purpose and Scope

Issue #39 requires three deliverables: a performance report, an 8-hour actual-Herdr soak log, and a human UAT decision. The existing gate (`tools/Test-V07PerformanceBudgets.ps1` plus `tools/lib/V07PerformanceBudgetPolicy.ps1`) defines the strict `v0.7.0` budget report schema, waiver rules, candidate hash binding, and deterministic self-test suite, but it only *evaluates* reports. Nothing in the repository *produced* the required live measurements.

This contract defines the missing **measurement producer**: a bounded, fail-closed operator harness that captures live launch p95, reconnect time, widget state-delta latency, idle CPU, and combined working set against an exact candidate/Herdr session, with exact commit/artifact/session/role provenance, cancellation and timeouts, raw sample retention, and no synthetic-to-runtime promotion.

The producer never starts or restarts Herdr itself (`SessionControlInvoked` is always false). The operator drives every session transition; the harness observes, times, binds, and retains evidence.

## Evidence boundary

| Class | Producer role |
|---|---|
| Static | Clean checkout, source commit binding, candidate executable SHA-256/length binding, reparse/path safety. |
| Synthetic | `-Synthetic` mode and the deterministic self-test fixtures produce artifacts with `Mode: Synthetic` that can never finalize to Runtime credit. |
| Contract | The finalizer emits a `v0.7.0` budget report whose admission is re-validated by the existing budget gate. |
| Runtime | A live run writes a `v0.7.0-measurement` artifact with `Mode: Live` and observed raw samples. The budget report is finalized only when a matching 8-hour soak artifact is also validated. |
| Soak / UAT / Release | Produced elsewhere; the finalizer requires the soak artifact and never fabricates UAT or release claims. |

### 2. Soak artifact (`SchemaVersion: v0.7.0-soak`)

A separate, future producer writes the 8-hour soak log. The finalizer accepts only this shape and validates duration, crash counts, unreconciled state, session/commit binding, and the **cross-file run-id/hash chain** that binds the soak log to its exact measurement artifact:

```json
{
  "SchemaVersion": "v0.7.0-soak",
  "ArtifactKind": "SoakRun",
  "RunId": "...",
  "StartedUtc": "...",
  "FinishedUtc": "...",
  "Mode": "Live",
  "Cancelled": false,
  "TimedOut": false,
  "MeasurementRunId": "<measurement artifact RunId>",
  "MeasurementArtifactSha256": "<canonical SHA-256 of the measurement artifact>",
  "Session": { "ControlHerdrSocketPath": "...", "TargetHerdrSocketPath": "...", "HerdrExecutableSha256": "..." },
  "Candidate": { "SourceCommit": "<40-hex>" },
  "Soak": { "DurationHours": 8.0, "UnhandledCrashes": 0, "UnreconciledStateCount": 0, "UnboundedTerminalReads": 0 }
}
```

`Soak.DurationHours` is cross-checked against `FinishedUtc - StartedUtc`. The
deterministic tolerance is exactly 1 second of permitted timestamp shortfall,
to account for timestamp serialization precision: `actualSpanSeconds + 1 >=
DurationHours * 3600`. A non-numeric, string, non-finite, negative, or otherwise
invalid duration; inverted or invalid timestamps; or a span shorter than the
declared duration beyond that 1-second tolerance fails closed. The tolerance
does not reduce the separate minimum requirement of 8 hours.

`MeasurementArtifactSha256` is the canonical SHA-256 (`Get-V07ArtifactCanonicalSha256`) of the exact measurement artifact it accompanies, and `MeasurementRunId` must equal that artifact's `RunId`. The finalizer recomputes both; any mismatch fails closed as a broken or forged cross-file chain.

### 3. Budget report (`SchemaVersion: v0.7.0`)

The finalizer (`ConvertTo-V07RuntimeBudgetReport`) transforms a *validated live* measurement artifact plus a *validated matching* soak artifact into the standard budget report with `EvidenceClass: Runtime`, `ProcessTelemetry` bound to the Core/App roles, and raw latency/launch samples retained. This report is re-validated by `Test-V07PerformanceBudgets.ps1` before any gate credit.

## Live measurement methods

| Budget metric | Measurement | Bounds |
|---|---|---|
| Dashboard cold launch p95 | App process spawn to the App's own progress telemetry phase `capturing-live-dashboard-and-widgets` (initial live state applied), across `-LaunchRuns` cold launches. | runs 3-10, per-run timeout, graceful close with kill fallback recorded |
| Widget state-delta latency p95 | `WidgetLatencyIncludedSamples` (`CoreAcceptedStateUtcToWpfStateApplied`) from the App runtime-evidence report. | ≥ 3 accepted samples retained |
| Herdr reconnect and reconcile | Core runtime trace transitions: time from the disconnect transition to the next Connected bootstrap with a fresh server identity. | ≥ 1 restart sample |
| Core + App idle CPU | Combined `TotalProcessorTime` deltas over a bounded idle window (operator keeps the session idle), normalized by wall time and processor count. | ≥ 3 samples |
| Core + App combined working set | Summed `WorkingSet64` samples of the bound Core and App processes over the same idle window. | ≥ 3 samples |

Every sample is retained with its timestamp and process binding. Aggregates (p95, mean) are recomputed from raw samples by the admission check and must match the declared metric within tolerance; otherwise the artifact fails closed.

## Fail-closed admission rules

`Test-V07MeasurementArtifactAdmission` rejects an artifact when any of the following hold:

1. **Missing evidence**: any declared-observed metric has fewer than its minimum raw samples; provenance fields are absent; role or session records are absent.
2. **Forged evidence**: `Observed` flags inconsistent with raw samples; declared aggregate does not recompute from raw samples; `Mode: Live` with zero samples; `Cancelled`/`TimedOut` yet observed; control server identity missing while claiming live; non-finite, negative, out-of-range, or out-of-window sample values; samples exceeding the per-metric retention cap; unknown or duplicate JSON properties, trailing content, NaN/Infinity literals, and fractional integers (rejected by the strict parser and strict-integer validation); role or server start times in the future; soak `MeasurementArtifactSha256`/`MeasurementRunId` mismatch.
3. **Stale evidence**: `Candidate.SourceCommit` does not equal the current clean HEAD (when evaluated with a repository root); declared binary lengths/SHA-256 do not match on-disk bytes; role binary hashes do not match the exact candidate bytes; a dirty `GitTreeClean` flag.
4. **Wrong-session evidence**: control socket equals target socket; recorded control pane id does not equal the observed pane id; control server identity does not match the admitted Herdr executable path/hash; role processes share one PID or are not bound to the correct role binary (`HerdrOps.Core` must bind `HerdrOps.Core.dll/exe`, `HerdrOps.App` must bind `HerdrOps.App.dll/exe`, never the CLI); soak session/commit/chain mismatch.
5. **Run integrity**: `Mode` is not `Live`; the run was cancelled or timed out; sample timestamps fall outside `[StartedUtc, FinishedUtc]`.

The finalizer additionally requires a valid matching soak artifact before emitting `EvidenceClass: Runtime`. A synthetic artifact can only ever finalize to a blocked result; the harness writes no Runtime budget report without complete, validated evidence.

## Cancellation and timeouts

- Every phase runs under a bounded deadline derived from `-MaxRunSeconds`; a global `CancellationToken` (Ctrl+C) cancels all phases.
- On cancellation or timeout the harness records the phase result, writes the measurement artifact with `Cancelled`/`TimedOut` true, and writes a gate report that explicitly denies Runtime credit. Partial raw samples are retained for diagnosis but never admitted.
- No phase may start Actual-Herdr, restart a session, or invoke session control.

## Operator procedure (live mode)

1. Open a fresh Acceptance control pane in the authorized Herdr environment (HERDR_ENV=1).
2. Prepare the target Agent Lab session and record its socket path.
3. Run `tools/Invoke-V07PerformanceMeasurement.ps1` with `-TargetHerdrSocketPath <target>` (see harness help).
4. Follow the phase instructions printed by the harness (trigger genuine Agent-status events, restart only the target Agent Lab session, keep the session idle during resource sampling).
5. Inspect `measurement-gate-report.txt`; never claim Runtime credit unless the report and artifact agree.
6. Provide the validated 8-hour soak artifact to the finalizer to produce the `v0.7.0` budget report; submit that report to `Test-V07PerformanceBudgets.ps1`.

## Repository hygiene

- All producer source, fixtures, and tests live under `tools/` and `tests/fixtures/v0.7/performance-measurement/`.
- Fixtures use stable but possibly stale candidate hashes; positive-control tests rebind to current HEAD and on-disk binaries through `New-SynthesizedLiveArtifact`, never by weakening the on-disk verification.
- No remote publication, no issue closure, and no Runtime credit without matching version-local evidence.
