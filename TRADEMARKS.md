The HerdrOps name, blue circular mark, and `HerdrOps` wordmark identify the project. A copyright license for source code, documentation, or artwork does not grant permission to claim sponsorship, endorsement, certification, or official-project status.

You may use the name and mark truthfully to refer to the unmodified HerdrOps project, to describe compatibility, and as required to run or redistribute an unmodified build under `LICENSE`. Modified versions must not imply that they are official or approved by the HerdrOps maintainers. Prominent modified distributions should use a distinct name and visual identity unless the maintainers grant written permission.

Upstream contributions must continue to preserve the approved mark and wordmark according to `Plan/DESIGN-CONTRACT.md`; that repository contribution rule does not require independent forks to represent themselves as HerdrOps.

“Herdr” and any associated names or marks belong to their respective owners. HerdrOps uses those names only to describe interoperability with an installed Herdr instance and does not imply affiliation or endorsement.
